## 为什么搭建博客

想给自己留一个地方，记录学习过程、整理技术笔记，也偶尔发布一些有的没的。

很多东西看过的时候觉得懂了，真正动手写代码、试着解释给别人听，才会发现还有不少细节没想清楚。这个博客就用来留下这些过程：遇到了什么问题，尝试了什么办法，最后又是怎么理解的。

不要求每篇都是完整教程。一个具体问题、一段代码、一次踩坑，整理清楚了就值得记下来。

> 2026 年 11 月 9 日更新：博客从 Hugo 迁移到 Astro。这篇开篇记录也同步更新，保留最初的发布日期和文章地址。

## 关于这个博客

最初用 **Hugo** 搭建，后来页面逐渐加上了个人展示卡片、兴趣模块和文档侧栏。功能变多了，但我更希望打开博客时，先看到文章本身。

这次改版迁移到了 **Astro**，页面采用自定义 CSS 和圆角卡片，以中性黑白灰为主。文章继续用 Markdown 编写，保存在 `content/posts/` 里。

目前保留的功能都围绕写作和阅读：

- **文章列表与标签**：按时间浏览，也可以从[标签页](/tags/)找到相关内容。
- **代码块与目录**：代码支持高亮和复制，较长的文章可以展开目录跳转。
- **明暗主题**：记住阅读偏好，切换时用一段简短的扩散动画过渡。
- **个人介绍与订阅**：[个人简历](/about/)、[GitHub](https://github.com/fetwtgrah) 和 [RSS](/rss.xml) 都有独立入口。

发布流程也已切换为 Astro：通过 GitHub Actions 检查和构建，再发布到 GitHub Pages。

## 慢慢写下去

页面先做到顺手，接下来把精力更多放回内容。每篇文章解决一个小问题，讲清楚背景、做法和结果；暂时没弄明白的地方，也可以先记下来。

希望以后回头看，这里不只是一些结论，也是自己一步步学习和实践的记录。
